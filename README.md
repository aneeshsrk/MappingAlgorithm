# Exoplanet Mineral Mapping Algorithm

This project was developed collaboratively as a team project focused on using NASA exoplanet data to predict and analyze potential mineral compositions.

## Project Overview

The project uses regularized linear regression and NASA exoplanet data to predict target mineral groups, rank exoplanets based on weighted metrics, and visualize selected systems using 3D astronomical coordinates.
